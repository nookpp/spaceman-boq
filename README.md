# 🏗️ AI BOQ Pro — ระบบสร้างและถอด BOQ อัจฉริยะ

ระบบ Web Application สำหรับสถาปนิก ผู้รับเหมา และวิศวกรประมาณราคา เพื่อถอดรายการปริมาณงาน (BOQ / Bill of Quantities) จากแบบแปลนก่อสร้าง (PDF / DWG / DXF) ส่งออกเป็นไฟล์ **Excel (.xlsx)** ตามแบบฟอร์มมาตรฐานของบริษัท ขับเคลื่อนด้วย **Streamlit + OpenCode Go (OpenAI-compatible)**

---

## 🌟 ฟีเจอร์เด่น (Key Features)

1. **รองรับแบบก่อสร้าง PDF เล่มใหญ่:**
   - ทดสอบกับแบบแปลนจริง `PLC HOUSE_Fortender.pdf` (134 หน้า)
   - มีระบบสแกนดัชนีอัตโนมัติ (Schedule & Index Scanner) ค้นหารหัสแบบ Built-in (J1-xx, J2-xx, D1-xx, E1-xx) ภายใน 3 วินาที
   - มีหน้าต่างดูแบบแปลนความละเอียดสูง (Drawing Viewer) ซูมดูได้ในตัว
2. **ขับเคลื่อนด้วย OpenCode Go:**
   - ใช้งานผ่านโมเดลทรงพลัง เช่น `deepseek-chat`, `deepseek-reasoner`, `qwen-2.5-72b-instruct`, `glm-4-plus`
   - มีโหมด **Demo Mode** สามารถทดลองใช้งานและทดสอบระบบได้ทันทีแม้ยังไม่มี API Key
3. **ตารางตรวจสอบและแก้ไขตัวเลขสด (Interactive BOQ Data Editor):**
   - ผู้ใช้และเพื่อนร่วมงานสามารถพิมพ์ปรับแก้ปริมาณ (Qty), หน่วย (Unit), ค่าวัสดุ, ค่าแรง ได้โดยตรงบนหน้าเว็บ
   - ผลรวมเงินคำนวณใหม่อัตโนมัติแบบ Real-time
4. **ส่งออกเข้าฟอร์ม Excel มาตรฐาน (`Blank BOQ_PLC HOUSE .xlsx`):**
   - ฝัง **สูตร Excel จริง** (`=(T+V)*Q`, `=SUM(...)`, และค่าดำเนินการ Overhead)
   - เชื่อมโยงแผ่นงาน `Summary` (ใบเสนอราคา) เข้ากับแผ่นงาน `BOQ` อัตโนมัติ 100%

## 🚀 วิธีการเปิดใช้งาน (Quick Start)

### วิธีที่ 1: ดับเบิลคลิกไฟล์เดียว
เพียงดับเบิลคลิกที่ไฟล์ **`run.bat`** ในโฟลเดอร์นี้ ระบบจะเปิดเว็บเบราว์เซอร์ให้อัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / Command Line
```powershell
cd D:\projects\boq-services
.\.venv\Scripts\streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

## 👥 วิธีทำให้เพื่อนๆ เข้ามาใช้งานร่วมกันได้

### 1. ใช้งานในออฟฟิศ / ไซต์งานเดียวกัน (Local Network / Wi-Fi)
- เมื่อรันคำสั่งด้านบน Streamlit จะแสดงที่อยู่ **Network URL** เช่น:
  `http://192.168.1.50:8501`
- เพื่อนที่ต่อ Wi-Fi หรืออยู่ในวง LAN เดียวกัน สามารถนำ URL นี้ไปเปิดในเบราว์เซอร์ของตัวเอง (ทั้งในคอมพิวเตอร์ แท็บเล็ต หรือมือถือ) เพื่อใช้งานได้ทันที

### 2. ใช้งานข้ามสถานที่ผ่าน Cloud (เปิดให้เพื่อนใช้จากที่ไหนก็ได้ ฟรี)
- อัปโหลดโปรเจกต์นี้ขึ้น **GitHub (Private Repository)**
- ไปที่ [share.streamlit.io](https://share.streamlit.io) แล้วล็อกอินด้วย GitHub
- เลือก Repository นี้แล้วกด **Deploy**
- คุณจะได้ลิงก์เว็บส่วนตัว (เช่น `https://my-boq-tool.streamlit.app`) ส่งให้เพื่อนเปิดใช้งานได้จากทั่วโลก 24 ชม.

## 📐 คำแนะนำเรื่องไฟล์แบบ `.dwg` และ `.pdf`
- **ไฟล์ PDF:** แนะนำให้ใช้ไฟล์ PDF ที่พิมพ์ (Plot to PDF) ออกมาจาก AutoCAD หรือ Revit เพราะระบบจะสามารถดึงทั้ง Layer ตัวหนังสือและเรนเดอร์ภาพได้อย่างคมชัด
- **ไฟล์ DWG:** ไฟล์ `.dwg` เป็นฟอร์แมตปิดของ Autodesk หากต้องการใช้งาน ให้ทำตามข้อใดข้อหนึ่ง:
  1. สั่ง **Export / Plot to PDF** จาก AutoCAD (เหมือนกับไฟล์ `PLC HOUSE_Fortender.pdf`) ซึ่งเป็นวิธีที่ดีที่สุด
  2. สั่ง **Save As เป็นไฟล์ `.dxf`** แล้วนำมาอัปโหลดเข้าสู่ระบบได้เช่นกัน
